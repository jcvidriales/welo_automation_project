# Welo Automation Project

Python automation project for processing and classifying movie and TV content using AI.

## Features

- Reads movie and TV data from a CSV file
- Classifies content automatically
- Uses AI to determine genres
- Exports classified results to a CSV file

## Technologies

- Python
- CSV
- AI API integration
- Git & GitHub

## How to Run

1. Clone the repository
2. Create and activate a Python virtual environment
3. Install the required dependencies
4. Add your API key to a `.env` file
5. Run the program:

```bash
python main.py
```
