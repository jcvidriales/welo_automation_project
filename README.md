# Welo Automation Project

A Python tool that reads a list of movies and TV shows from a CSV file, classifies each one by **genre** (using AI), **duration category** and **content type**, and exports the results to a new CSV file.

## Example

**Input:** `input_movies.csv`

| title | description | duration_minutes | type |
|---|---|---|---|
| The Dark Knight | A masked hero faces a dangerous criminal who threatens the city. | 152 | Movie |
| Toy Story | Toys come to life when humans are not around. | 81 | Movie |
| Stranger Things | A group of friends encounters supernatural events in their town. | 50 | TV Show |

**Output:** `classified_movies.csv`

| title | genre | duration_category | type |
|---|---|---|---|
| The Dark Knight | Superhero | Long | Movie |
| Toy Story | Animation | Short | Movie |
| Stranger Things | Supernatural | Medium | TV Show |

## How It Works

1. **Reads and validates the input.** The program checks that the CSV exists and has the required columns, and skips rows with missing data, an invalid duration, or an unknown content type.
2. **Normalizes the content type.** Values like `movie`, `MOVIE` or ` Movie ` are all converted to `Movie` (same for `TV Show`).
3. **Classifies the duration.** Movies and TV episodes use different ranges:

   | Type | Short | Medium | Long |
   |---|---|---|---|
   | Movie | < 90 min | 90–120 min | > 120 min |
   | TV Show (per episode) | < 30 min | 30–60 min | > 60 min |

4. **Classifies the genre with AI.** The description is sent to the OpenAI API with a fixed list of allowed genres: Action, Comedy, Drama, Horror, Romance, Animation, Superhero, Supernatural. If the AI returns anything outside that list, the call fails, or the description is too short, the genre is set to `Unknown`, so the output always stays clean.
5. **Exports the results** to `classified_movies.csv`.

## Technologies

- `python-dotenv` for environment variables

- Git & GitHub

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/jcvidriales/welo_automation_project.git
   cd welo_automation_project
   ```
2. Create and activate a virtual environment:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate        # Windows
   source .venv/bin/activate     # macOS / Linux
   ```
3. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Create a `.env` file in the project folder with your OpenAI API key:
   ```
   OPENAI_API_KEY=your-api-key-here
   ```
5. Run the program:
   ```bash
   python main.py
   ```
